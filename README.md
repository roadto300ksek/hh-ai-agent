# Мультиагентная система автоматизации поиска и первичного отбора (AI-агент)

Учебный пет-проект, демонстрирующий навыки автоматизации бизнес-процессов с использованием Python и LLM. 

## 🎯 Задача
Автоматизировать рутинный процесс: сбор данных (вакансий), их семантический анализ, генерацию персонализированных текстов и выполнение целевых действий в браузере.

## 🧠 Архитектура
Система разделена на 4 независимых модуля (агента), которые общаются между собой через JSON-файлы:
1. **`hh_login.py`** — авторизация и сохранение сессии (cookies).
2. **`hh_scanner_multi.py`** — сканер. Собирает данные с динамического сайта с помощью Playwright. Обходит антибот-защиту.
3. **`hh_analyzer.py`** — аналитик. Прогоняет данные через LLM (DeepSeek API), оценивает релевантность (0-100) и фильтрует мусор.
4. **`hh_writer.py`** — копирайтер. Генерирует уникальные сопроводительные тексты под каждый объект.
5. **`hh_executor.py`** — исполнитель. Выполняет действия (отправляет отклики) с эмуляцией человеческого поведения (рандомные паузы, обработка капчи).

## 🛠 Стек технологий
* **Язык:** Python 3
* **Автоматизация браузера:** Playwright
* **Работа с LLM:** OpenAI SDK (DeepSeek API)
* **Форматы данных:** JSON
* **Парсинг:** BeautifulSoup / DOM-селекторы
* Интерфейс: Streamlit (веб-дашборд для мониторинга статистики и запуска агентов)*

## 🚀 Результаты
* Один прогон обрабатывает **460+ карточек** данных.
* ИИ-фильтр отсеивает **75% нерелевантного мусора**.
* Время на рутину сокращено с 3-4 часов до 15 минут в день.

## ⚙️ Установка и запуск
1. Установите зависимости: `pip install playwright openai`
2. Установите браузеры: `playwright install`
3. Вставьте ваш API-ключ DeepSeek в файлы `hh_analyzer.py` и `hh_writer.py`.
4. Запустите по очереди: `hh_login.py` -> `hh_scanner_multi.py` -> `hh_analyzer.py` -> `hh_writer.py` -> `hh_executor.py`
